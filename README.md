## 💻 Getting Started Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.x or newer)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### 1. Clone the repository
```bash
git clone https://github.com/soham-10-byte/Portfolio.git
cd Portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```
Update your contact email or form endpoint in `.env`:
```env
VITE_FORMSUBMIT_ENDPOINT=https://formsubmit.co/ajax/sensoham2005@gmail.com
VITE_CONTACT_EMAIL=sensoham2005@gmail.com
```

### 4. Start the development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 5. Build for production
```bash
npm run build
```
